# Alafi Baramme — Portfolio

Le dépôt est organisé en deux applications indépendantes :

- **front-end/** : portfolio web Alafi Baramme / Codecontenu (TanStack Start, React, Vite).
- **backend/** : API Node.js indépendante, avec un endpoint de santé `GET /api/health`.

## Développement

Frontend :
```bash
cd front-end
bun install
bun run dev
```

Backend :
```bash
cd backend
npm run dev
```

Le frontend et le backend se lancent séparément. Le portfolio existant reste dans `front-end/`.
